# 🏋️‍♂️ AI Fitness Coach (智能深蹲计数器)

这是一个利用计算机视觉技术（Computer Vision）实现的网页版健身教练。它利用三角函数和状态机逻辑，实时分析你的运动姿态。

## 🧠 技术原理

1.  **关键点提取**: 使用 `PoseNet` 提取人体骨骼点，重点关注 **左髋(Hip)**、**左膝(Knee)**、**左踝(Ankle)**。
2.  **几何计算**: 利用反三角函数 `Math.atan2` 计算这三点形成的夹角。
3.  **状态机 (State Machine)**:
    - `UP State`: 角度 > 160° (站直)
    - `DOWN State`: 角度 < 90° (深蹲)
    - 只有当状态从 `UP` -> `DOWN` -> `UP` 完整流转时，计数器加 1。
4.  **TTS 反馈**: 调用浏览器原生的 `SpeechSynthesis` API 进行语音报数和纠错。

## 🚀 使用方法

1.  **侧身站立**: 为了让 AI 最清楚地看到你的腿部弯曲角度，请**侧面对着摄像头**。
2.  **全身入镜**: 确保摄像头能看到你的腰部到脚部。
3.  **开始运动**: 
    - 慢慢下蹲，直到数字变为“下蹲”。
    - 站起来，直到听到语音报数。

## 📂 文件结构
- `index.html`: UI 界面
- `style.css`: 运动风格样式
- `script.js`: AI 模型加载、角度计算与逻辑判断
